# Cooking Anywhere

Cooking Anywhere lets you turn any tile into a cooking spot with Tile Marker. Face a marked tile
and press your normal action button to open the same cooking flow used by a regular kitchen.

## Requirements

- SMAPI
- Content Patcher 2.9.0 or newer
- Tile Marker 1.1.0 or newer

## How to use

1. Open Tile Marker using the key configured for it.
2. Choose **Cooking spots** (or **Pontos de cozinha** in Portuguese).
3. Mark the tiles you want to use and save.
4. Face one of those tiles and press the game's normal action button.

You can mark tiles in any location available to your save. The marks are stored by Tile Marker.

## Compatibility

The mod runs the game's normal `Kitchen` map action instead of creating a separate cooking menu.
That lets mods such as Better Crafting handle the kitchen activation through their existing
integration. Ingredient and remote-storage behavior remains controlled by the cooking and storage
mods you already use.
