# Looking at Sebastian

A Stardew Valley mod that adds unique reactions and special dialogue for Sebastian when you stare at him a little too long.

## Requirements

- Stardew Valley 1.6+
- SMAPI 4.0+

## Installation

1. Install SMAPI.
2. Download the latest mod release.
3. Extract the `Looking at Sebastian` folder into your Stardew Valley `Mods` folder.

## Build from source

```powershell
dotnet build LookingAtSebastian.slnx
```

The build deploys the mod to the configured Stardew Valley `Mods` directory.
